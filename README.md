# Landing Page

Landing page de alta conversão para divulgação de serviços de desenvolvimento de sites, landing pages, hospedagem e venda de templates.

## Publicação

Arquivo único `index.html`, sem dependências além do Google Fonts. Para publicar:

- **GitHub Pages**: Settings > Pages > Source: `main` / root.
- **Hospedagem própria**: enviar `index.html` para a raiz do servidor via FTP/SSH.
